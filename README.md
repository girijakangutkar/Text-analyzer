# Text Analyzer App

A responsive React application that provides real-time analysis of user-inputted text. As users type into the text box, the app calculates and displays key metrics including word count, character count, sentence count, number of pronouns, estimated reading time, and the longest word found in the input.

## Features

- Live word, character, and sentence counting
- Pronoun detection for basic linguistic analysis
- Average reading time estimation based on input length
- Longest word identification for vocabulary insights
- Clean and responsive UI for desktop and mobile
- Modular React components for maintainability

## Tech Stack

- React
- CSS
